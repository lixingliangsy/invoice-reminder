# Dunner — Use Cases

## Persona 1 — Solo freelancer
**Pain:** Hates asking for money; lets invoices slide.
**How:** Enter client + amount + days overdue → get 3 ready emails, pick the tone.

## Persona 2 — Small studio owner
**Pain:** Multiple late clients, no bandwidth to chase.
**How:** Sequences (Pro) run the Friendly → Firm → Final arc per client.

## Persona 3 — Agency account lead
**Pain:** Needs consistent, brand-voiced reminders across account managers.
**How:** Brand voice + API (Team) keeps every nudge on-message.

## Vertical notes
- Consultants: net-terms follow-up without friction.
- Creators: retainer renewal nudges.
