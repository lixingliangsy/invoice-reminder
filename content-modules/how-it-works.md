# Dunner — How It Works

## Step 1 — Enter the facts
Client name, amount owed, days overdue, tone.

## Step 2 — Get 3 reminders
Friendly, Firm, and Final drafts — professional, copy-ready.

## Step 3 — Send (or sequence)
Paste one now, or run a sequence (Pro) across overdue clients.

> Demo mode returns a heuristic draft. Add `OPENAI_API_KEY` for tone-tuned, multi-thread sequences (`source: 'Model-assisted'`).
